# NotebookLM prompt and quality-check log

## Source-grounded question

Using only the selected sources, explain what NASA DART changed about Dimorphos's orbit and what uncertainties remain before kinetic impact could be relied on for a real threat. Cite the supporting sources.

## Additional prompts to try

1. **Explain the full chain:** Build a five-step flow from asteroid discovery to possible deflection. Cite at least one source for each step.
2. **Compare missions:** Compare DART and Hera by objective, spacecraft action, measurements, and what each can and cannot establish.
3. **Off-topic check:** What is the best treatment for a human knee injury? If the sources cannot answer this, say so rather than using outside knowledge.
4. **Source check:** What does CNEOS do, and which source supports each part of the answer?
5. **Audio overview:** Create an audio conversation for a first-year engineering student explaining detection, DART, Hera, and uncertainty.
6. **Quiz / flashcards:** Generate 8 review questions. Include answer keys with source citations; include at least two questions about uncertainty.
7. **Slide deck:** Create a 6-slide briefing: hazard, detection, orbit/risk assessment, DART, Hera, open questions. Cite factual claims.
8. **Mind map:** Organize the topic as detect → track → characterize → decide → mitigate, with missions and sources under each branch.

## Verification checklist

- Does every factual answer stay within the selected sources?
- Do the citations open the passages that support the claim?
- Is the 32-minute initial DART period change correctly described as Dimorphos orbiting Didymos?
- Are DART's measured results separated from Hera's future/ongoing investigation and NEO Surveyor's planned objectives?
- Does the off-topic test acknowledge the source boundary?
- Check generated audio, quiz/flashcards, slide deck, and mind map for unsupported claims before sharing.
